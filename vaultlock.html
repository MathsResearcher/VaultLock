Under the hood

  

    
Key derivation
PBKDF2-HMAC-SHA256, 400,000 rounds, random 16-byte salt. One derivation yields separate encryption and MAC keys. An optional key file is hashed and mixed in.

    
Authenticated
Every mode detects tampering: GCM tags, or encrypt-then-MAC with HMAC-SHA256 checked before decryption. Wrong keys fail cleanly.

    
Self-describing
Output carries a magic header, method ID, salt and nonce. The original filename is encrypted inside, so extensions are restored on decrypt.

    
Steganography
Append mode adds a trailer behind any file. Pixel mode writes bits into the lowest bit of image colour channels. Both carry the encrypted payload only.
